# ProjectFlow - Next.js Internship Capstone

ProjectFlow is a Next.js App Router project for a project-management internship capstone.

## Quick Start

1. Install dependencies

```bash
pnpm install
```

2. Start development server

```bash
pnpm dev
```

3. Open http://localhost:3000

## Scripts

- `pnpm dev`
- `pnpm build`
- `pnpm start`
- `pnpm lint`

## Notes

- This repository contains active in-progress implementation work.
- Authentication is handled with Clerk.
- Database uses Drizzle ORM with PostgreSQL/Neon.
